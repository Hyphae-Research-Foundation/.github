# Hyphae Research Foundation GitHub profile

Source for the organization-level `.github` repository at
`Hyphae-Research-Foundation/.github`.

The `profile/README.md` file is rendered on the organization profile. Root
community-health files are defaults for organization repositories that do not
provide stricter project-specific versions.

## Publication

This directory is intended to become the root of a public repository named
`.github` under the Hyphae Research Foundation organization.

Before publication:

1. Confirm the organization login.
2. Confirm current legal-status wording.
3. Push only after the organization exists and its owner has enabled 2FA.

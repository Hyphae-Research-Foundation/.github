# Security

Do not disclose suspected vulnerabilities in public issues, Discussions, pull
requests, or chat.

- For Hyphae, use GitHub private vulnerability reporting at
  https://github.com/Hyphae-Research-Foundation/hyphae/security.
- Hyphae Inference is in private development and has no supported public
  release.
- For the organization profile, use private vulnerability reporting on this
  repository when enabled.

Include the affected revision, platform, reproduction steps, impact, and any
proposed mitigation. Do not include unrelated secrets or personal data.

We aim to acknowledge a complete report within seven calendar days. This is a
best-effort bootstrap target, not a service-level agreement.

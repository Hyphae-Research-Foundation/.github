# Support

Community support is best effort. No service-level commitment is implied.

- Use the relevant repository's Discussions for questions and early ideas.
- Use structured issues for reproducible defects and approved work.
- Follow `SECURITY.md` for suspected vulnerabilities.
- Use the Hyphae Transformer issue tracker for reproducible framework defects.
- Use the Hyphae BitNet issue tracker for runtime defects, including exact
  version, model digest, CPU profile, command, and non-sensitive logs.

Include an exact release or commit, environment, reproduction, expected
behavior, actual behavior, and the smallest non-sensitive diagnostic output.
